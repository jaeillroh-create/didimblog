# [신규·초안] 지원사업 공고를 추천 소스로 받는 입력 슬롯

> 원본 코드에 없는 기능이다(docs/skills-spec/didim-blog-planner.md 8절 '신규').
> 지금은 **선택 입력 정의 + 주제화 규칙 초안**만 둔다. 스크립트는 판정하지 않으며 Claude 가 아래 규칙대로 직접 판단한다.

## 1. 입력 슬롯 `grant_items[]` (선택)

지원매치 일일 리포트(정부·지자체 지원사업 공고 요약)를 사용자가 붙여넣거나, 지원사업 검색 커넥터가 있으면 그 결과를 쓴다.

| 필드 | 필수 | 예 |
|---|---|---|
| title | 필수 | 2026년 하반기 IP 나래 프로그램 참여기업 모집 |
| agency | 선택 | 한국발명진흥회 |
| deadline | 권장 | 2026-10-20 |
| url | 권장 | 공고 원문 링크 |
| eligibility | 권장 | 신청 자격 원문 |
| bonus | 권장 | 가점·우대 조건 원문 |
| support | 선택 | 지원 내용(금액·서비스) |

## 2. 주제화 규칙 초안

1. **특허·인증이 요건이거나 가점일 때만** 후보로 삼는다. `eligibility` 또는 `bonus` 원문에 다음 중 하나가 있어야 한다:
   특허, 실용신안, 디자인권, 상표, 지식재산, IP, 직무발명, 기업부설연구소, 연구전담부서, 벤처기업(인증·확인), 이노비즈, 메인비즈, 기술평가, 우선심사.
   제목에만 나오고 자격·가점에 없으면 제외한다(디딤 서비스로 이어지지 않으므로).
2. 요건/가점 종류로 카테고리를 정한다.
   - 기업부설연구소·연구전담부서·벤처·이노비즈·메인비즈 → 변리사의 현장 수첩 / 인증 가이드
   - 특허·상표·디자인 보유 또는 출원 → 변리사의 현장 수첩 / 특허·상표 출원 실무
   - 직무발명보상제도 운영 → 변리사의 현장 수첩 / 절세 시뮬레이션
   - IP 전략·포트폴리오·기술가치평가 → IP 라운지 / 특허 전략 노트
   - 공고 자체를 짧게 알리는 글 → IP 라운지 / IP 뉴스 한 입
   - 디딤 다이어리로는 만들지 않는다(다이어리는 CTA 금지·브랜딩 글).
3. 마감이 7일 이내면 우선순위 URGENT, 그 외 PRIMARY 후보. 마감이 지났으면 버린다.
4. 제목안은 공고명을 그대로 쓰지 말고 "요건/가점을 갖추는 방법" 관점으로 쓴다(예: "지원사업 가점 받는 특허 1건, 언제까지 출원해야 할까").
5. 근거 소스 칸에 `지원사업 공고(신규)` + 공고 URL 을 적는다. 선정·합격을 보장하는 표현은 쓰지 않는다.
6. 공고 내용(금액·마감·자격)은 원문 링크로 사실 확인을 했다고 표시하고, 확인 못 했으면 "공고 원문 확인 필요"를 붙인다.

### 8.2 복사 기능 구현

모든 [복사] 버튼은 `navigator.clipboard.writeText()`로 **순수 텍스트만** 복사. HTML 태그 절대 포함 금지. 복사 성공 시 버튼 텍스트 "복사됨 ✓" 2초간 표시 후 원복.

본문 복사 시: 마크다운 구문(`##`, `**`, `` ``` `` 등) 전부 제거. 소제목은 줄바꿈 + 텍스트로만.

## 2. 기획 vs 구현(코드) 차이
| 항목 | §8 기획 | 코드 구현 | 스킬 처리 |
|---|---|---|---|
| 복사 방식 | 모든 복사는 순수 텍스트, HTML 절대 금지 | 본문에 "서식 포함 복사"(HTML) 추가, 나머지는 순수 텍스트 | 기본은 순수 텍스트 블록. HTML 은 요청 시에만 `body_html` 제공 |
| 서식 가이드 (행 번호) | "1행 … → 네이버 제목2", "28행 ━━━ → 구분선", "3행 뒤 → 이미지1" | 미구현. 카테고리별 고정 포맷 가이드(generateFormatGuide)만 | scripts `line-guide`(스킬 추가)로 복사용 본문 기준 행 번호 안내 생성 |
| 이미지 가이드 | 썸네일 오렌지 계열 1200×630px, 본문 2장 + 인포그래픽 1장 | [IMAGE:] 마커 목록 + ALT | 마커 목록 + (스킬 추가) 여러 줄 이미지 블록 감지. 썸네일 규격은 코드 FIRST_IMAGE_RULES(1:1, 1080×1080)와 §8(1200×630)이 다름 → **확인 필요**, 인포그래픽 스킬 기준을 따름 |
| 태그 표기 | "직무발명보상금절세, 법인세줄이는방법, …"(쉼표) | `#태그 #태그`(100자 이내) | 코드 형식 |
| 체크리스트 | 본문 붙여넣기 / 소제목 제목2 / 이미지 3장+ALT / 구분선+CTA 서식 / 태그 10개 / 화요일 09:00 예약 발행 / PC+모바일 미리보기 | 제목 복사 / 본문 복사 & 붙여넣기 / 이미지 삽입(ALT) / CTA 복사 & 배치 / 태그 10개 / 네이버 에디터 포맷 / 미리보기 | 코드 7개를 체크리스트로 쓰고, §8 의 "화요일 09:00 예약 발행", "PC + 모바일" 은 해당 항목의 확인 포인트로 덧붙임 |
| 면책조항 | 없음 | 면책조항 카드 있음 | 코드대로 포함 |

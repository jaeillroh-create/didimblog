# 브라우저 직접 발행 (에이전트 발행 모드)

브라우저를 조작할 수 있는 AI(예: ChatGPT 에이전트 모드, Claude in Chrome·Claude 브라우저 등)는 발행 블록을 사람이 붙여넣는 대신 **네이버 블로그 에디터에 직접 입력하고 예약·발행**할 수 있다. 브라우저 도구가 없으면 기존처럼 발행 블록을 사람에게 넘긴다.

대표의 실제 블로그에 공개되는 일이므로, 아래 **발행 게이트**를 모두 통과한 글만, **사람의 마지막 확인**을 받은 뒤 발행한다.

## 1. 발행 게이트 (모두 충족해야 진행)
Notion "디딤 블로그 콘텐츠" 해당 행 기준.

| 조건 | 열 | 통과 값 |
|---|---|---|
| 상태 | 상태 | `S2 검토완료` 또는 `S3 발행예정` |
| 대표 검수 | 검수 상태 | `승인` |
| 팩트 검증 | 교차검증 | `통과` (`미실시`·`심각 이슈 남음`이면 중단) |
| SEO | SEO 판정 | `통과` 또는 `수정 필요` (`발행 불가`면 중단) |
| 발행 블록 | 페이지 `## 발행 블록` | publish-prep 결과가 들어 있음 |
| 이미지 | 인포그래픽 PNG | 파일이 준비됨(없으면 이미지 없이 진행할지 사람에게 묻는다) |
| 다이어리·사무소 소식 | CTA | `없음` 이어야 함 |

하나라도 어긋나면 발행하지 않고, 무엇이 막혔는지 사람에게 알린다.

## 2. 사람 확인 지점 (건너뛰지 않는다)
1. **시작 전**: "『(제목)』을 (카테고리)에 (예약 시각 또는 즉시) 발행합니다. 진행할까요?" — 명시적 승인(예: "발행해")을 받는다.
2. **발행 버튼 직전**: 발행 설정 화면(카테고리·공개 범위·태그·발행 시각)을 스크린샷이나 요약으로 보여 주고 마지막 승인을 받는다.

## 3. 하지 않는 것
- 비밀번호를 묻거나 입력하지 않는다. 네이버 로그인·캡차·2단계 인증은 사람이 한다. 로그인 화면이 나오면 멈추고 사람에게 넘긴다.
- 승인되지 않은 글, 게이트를 통과하지 못한 글을 올리지 않는다.
- 이미 발행된 글을 수정·삭제·비공개 전환하지 않는다(요청이 있으면 별도 확인 후 그 작업만).
- 하루에 여러 편을 연달아 올리지 않는다(기본 1편). 대량·반복 게시는 네이버 운영정책상 어뷰징으로 보일 수 있다.
- 디딤 소개·상담 안내 같은 고정 페이지를 건드리지 않는다.
- 블로그 설정·카테고리 구조·이웃 관리 화면을 바꾸지 않는다.

## 4. 절차 (스마트에디터 ONE 기준)
화면 문구와 위치는 네이버 개편으로 바뀔 수 있다. **보이는 버튼 이름을 기준으로** 하고, 확신이 없으면 스크린샷을 찍어 확인한다.

1. `https://blog.naver.com/didimip` 에서 **글쓰기**를 연다(또는 `https://blog.naver.com/didimip/postwrite`). 로그인되어 있지 않으면 멈추고 사람에게 요청한다.
2. "작성 중인 글이 있습니다" 같은 임시저장 복원 창이 뜨면 **취소**(새 글로 시작). 복원이 필요한지 애매하면 사람에게 묻는다.
3. **제목**: 발행 블록 `[1] 제목`을 제목 칸에 입력한다.
4. **본문**: 발행 블록 `[2] 본문`을 위에서부터 입력한다.
   - `[7-1] 서식 행 가이드`에 따라 소제목 줄은 에디터의 소제목(제목2) 서식, `━━━` 줄은 구분선으로 바꾼다.
   - 이미지 위치 표시(`[IMAGE …]`, "이미지 N 삽입")가 나오면 그 자리에서 **사진** 버튼으로 해당 PNG를 올리고, 대체텍스트(ALT)에 `[6]`의 ALT를 넣는다. 표시 문구 자체는 지운다.
   - `[2-1] 표 데이터`가 있으면 **표** 블록을 넣고 TSV를 붙여넣는다.
5. **면책·CTA**: `[3] 면책조항`과 `[4] CTA`를 본문 끝(CTA 구분선 앞뒤 순서 그대로)에 넣는다. CTA가 "없음"인 글은 넣지 않는다.
6. **발행 설정** — 오른쪽 위 **발행** 버튼을 누르면 설정 패널이 열린다.
   - **카테고리**: Notion `카테고리`(레거시면 `2차 분류`) 이름과 글자까지 같은 항목을 고른다.
   - **공개 설정**: 전체공개.
   - **태그**: `[5] 태그`의 태그를 하나씩 입력(최대 10개).
   - **발행 시간**: 기본은 **예약** → Notion `발행예정일`의 **화요일 09:00**. 사람이 "지금 발행"을 지시했을 때만 즉시 발행.
   - 그 밖의 옵션(댓글·공감 허용 등)은 기본값 유지.
7. **마지막 확인(2절 2번)** 후 패널의 **발행**(예약이면 예약 발행) 버튼을 누른다.
8. **결과 확인**
   - 즉시 발행: 열린 글 주소(`https://blog.naver.com/didimip/<글번호>`)를 확인한다.
   - 예약 발행: 예약 글 목록에서 시각이 맞는지 확인한다. 발행 시각이 지나면 RSS(`https://rss.blog.naver.com/didimip.xml`)나 블로그에서 글 주소를 확인한다.
   - PC·모바일 보기에서 이미지·소제목·CTA가 깨지지 않았는지 훑어본다.
9. **기록** (사람 확인 없이 해도 되는 사실 기록)
   - 예약 발행 완료 → `상태` = `S3 발행예정`, `발행예정일` = 예약 날짜.
   - 실제 발행 확인 → `상태` = `S4 발행완료`, `발행일` = 실제 날짜, `발행 URL` = 글 주소.
   - 페이지 `## 검수 기록`에 한 줄: `YYYY-MM-DD 브라우저 발행(예약|즉시) — 에이전트명, 확인자`.

## 5. 문제가 생기면
- 입력 중 서식이 크게 깨지거나 이미지 업로드가 실패하면, **임시저장**만 하고 멈춘 뒤 사람에게 넘긴다(발행하지 않는다).
- 카테고리 목록에 Notion 카테고리와 같은 이름이 없으면 발행하지 않는다(카테고리 구조 변경 여부를 사람에게 확인).
- 같은 제목의 글이 이미 발행돼 있으면 중복 발행하지 않는다.
